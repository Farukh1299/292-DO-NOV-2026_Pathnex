## Ansible Task - Install Ngnix on Pathnex Server

----
-name Install Ngnix on Pathnex Server

host:all

become:yes

task:

-name:Install nginx
yum:
name:nginx
state:present

## Kubernets Task - Create Nginx Pod

kind:pod
metadata:
name pathnex pod
spec:
containers:
image:nginx:latest
ports:
-containerPort:80
